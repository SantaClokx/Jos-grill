# JO'S Grill

A responsive restaurant ordering website for JO'S Grill, Elelenwo, Rivers State.

## Features
- Mobile-first restaurant landing page with accessible navigation.
- Searchable menu with category filters.
- Interactive cart with quantity controls, item removal, and automatic NGN totals.
- Checkout form with customer name, phone, delivery address, and optional order notes.
- Structured WhatsApp order handoff to **+234 708 345 0350**.
- No customer account or payment integration required.

## Run locally
Open `index.html` in a browser. The site is dependency-free and can be hosted on GitHub Pages, Vercel, or any static host.

## Important launch checks
The menu items and prices are sample values from the supplied concept. Confirm them with JO'S Grill before launch. Confirm opening hours, delivery coverage/fees, and food photography. Delivery is deliberately marked for confirmation in WhatsApp; no fee is calculated on the site.

## Design notes
Warm ivory canvas, deep charcoal typography, tomato-red accents, food-led imagery, responsive layout, visible focus states, reduced-motion support, and keyboard-accessible cart interactions. UI direction follows the UI UX Pro Max inspiration brief.
